{% docs retailpulse_overview %}
RetailPulse is a fictional e-commerce company.
This dbt project transforms raw retail data
into analytics-ready mart models for reporting
and business intelligence.
{% enddocs %}

{% docs customer_id %}
Unique identifier for each customer.
Generated by the CRM source system.
Primary key across all customer-related models.
{% enddocs %}

{% docs order_id %}
Unique identifier for each order.
Generated by the order management system.
Primary key across all order-related models.
{% enddocs %}

{% docs customer_segment %}
Customer value segment assigned by CRM.
Values: BRONZE, SILVER, GOLD, PLATINUM.
Based on cumulative purchase history.
{% enddocs %}

{% docs order_status %}
Current status of the order in the fulfillment pipeline.
Values:
  PENDING   → Order placed, not yet confirmed
  CONFIRMED → Payment confirmed
  SHIPPED   → Dispatched from warehouse
  DELIVERED → Successfully delivered
  CANCELLED → Cancelled before delivery
  RETURNED  → Returned after delivery
{% enddocs %}

{% docs dbt_loaded_at %}
Timestamp when the record was loaded into
the Snowflake landing table by the ingestion pipeline.
Used for incremental model filtering.
{% enddocs %}
